# CNN Compression

This repo contains the code for a research project focusing exploring the effects of model compression techniques, such as quantization and pruning, on metrics such as accuracy, latency, throughput, model size, and power estimations.

More details can be found in the report.

The alexnet, resnet32, and squeezenet directories contain the checkpoints for various points in the training cycle. 

The benchmarks directory contains more checkpoints and more importantly the source code inside the models subdirectory.
